# La Estancia Global Homes

Quiero crear un sitio web en el cual los dueños de cassa puedan subir imagenes y descripciones sobre sus casas, para venta y renta. Entonces el usuario cliente puede ver las distintas opciones que tiene, incluido el precio, esto es para todos los paises del mundo, osea que desde españa puedo comprar una casa en cuba por ponerte un ejemplo.Ademas contara con un admin general con todas los permisos. El sitio se llama La Estancia. Preguntame lo que necesitres antes y durante la ejecucion
