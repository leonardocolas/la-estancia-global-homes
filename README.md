# La Estancia Global Homes

La Estancia is a real-estate website where owners can publish homes for sale or rent,
and customers can browse listings and prices across countries. The project is intended
to include a general administrator with full permissions. Ask the user to clarify
requirements that are not defined in the current implementation.

## Development

This repository uses Bun and includes a `bun.lock` lockfile.

```sh
bun install
bun run dev
```

Other available checks:

```sh
bun run lint
bun run build
```
